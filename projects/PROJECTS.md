# The eight capstone builds

These are evaluated engineering projects, not lectures. Each project gets a repository subfolder, data provenance and experiments.
#
| Project | Weeks | Required proof |
|---|---|---|
| [NumPy machine learning toolkit](01-classical-ml/README.md) | Weeks 05–10 | Train/validation/test splits without leakage |
| [Scalar autodiff and MLP engine](02-autograd/README.md) | Weeks 11–16 | Finite difference checks for branching and shared nodes |
| [PyTorch language-model experiments](03-deep-learning/README.md) | Weeks 17–22 | Train/dev/test negative log likelihood |
| [Own tokenizer and decoder-only GPT](04-tiny-gpt/README.md) | Weeks 23–32 | Tokenizer Unicode round-trip tests |
| [Gridworld and Q-learning/DQN](05-learned-agent/README.md) | Weeks 33–36 | Random policy baseline |
| [REINFORCE, actor-critic and PPO](06-policy-learning/README.md) | Weeks 37–40 | Correct log-probability use |
| [Instruction and preference learning experiments](07-post-training/README.md) | Weeks 41–43 | Source/license provenance for chosen pretrained model if used |
| [Safe tool-using agent and research report](08-llm-agent-research/README.md) | Weeks 44–48 | Tool allowlist, schema validation and max-step limit |
