# NumPy machine learning toolkit

**Timing:** Weeks 05–10

## Scope

Implement univariate and multivariable linear regression, logistic regression, a decision tree, k-means, a simple PCA, and a reproducible evaluator. These are YOUR algorithms; use scikit-learn only for comparison after correctness.

## Acceptance gates

- [ ] Train/validation/test splits without leakage
- [ ] Numerically validated regression gradients
- [ ] A tree and k-means tested on controlled toy data
- [ ] Model comparison table with simple baselines
- [ ] Report seed, overfitting, error cases and learned parameters

## Deliverable structure

```text
README.md    — this specification plus your design decisions
src/         — your own algorithms (create when you start)
tests/       — correctness checks (create when you start)
reports/     — reproducible experiment notes (create when you start)
```

## Before seeing reference solutions

Make a hypothesis, write a minimal prototype, add tests and compare with mathematical/numerical ground truth. Note failure modes and hardware limits.
