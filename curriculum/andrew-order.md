# Exact Andrew Ng viewing path

**Official course:** [Machine Learning Specialization — DeepLearning.AI](https://www.deeplearning.ai/specializations/machine-learning)

Andrew's lectures are the foundation **for six selected curriculum weeks**, not the only course you need. The current three-course specialization has more material than you need to watch linearly now. Video/module labels below are copied as **short course section identifiers**, not video transcripts or course content. Coursera/DeepLearning.AI may reorder content, so navigate by subject when labels change.

| Our week | Official section to study | Watch for | Implement immediately |
|---|---|---|---|
| 05 | **Course 1 Week 1** — Introduction to ML, Regression Model, Train with Gradient Descent | Definitions, parameters, cost function, gradient descent | Univariate linear regression from scratch |
| 06 | **Course 1 Week 2** — Multiple Linear Regression, Gradient Descent in Practice | Vectorization, feature scaling, convergence | Multivariable regression + scaling |

| 10 | **Course 3 Week 2** — PCA portion; **Course 3 Week 3** — RL introduction and state-action value overview | Dimensionality reduction; what RL optimizes | PCA + classical ML capstone; RL preview |

## What to leave for later

- Course 2 Weeks 1–2 (neural networks + network training): skim for intuition during weeks 11–17, **but build and differentiate the network yourself with Karpathy**; avoid spending time mastering TensorFlow now.
- Extensive recommender-system implementations: optional if interested, not a prerequisite for LLM training.
- TensorFlow assignments, certificates and paid labs: optional. Replace with the original NumPy exercises here where access is restricted.
- Course 3 RL exercises: preview now, do the deeper algorithms in weeks 33–40.

## How to watch effectively

1. Watch a short conceptual segment.
2. Pause and write the formula in your own words.
3. Code it in NumPy before watching an implementation walkthrough.
4. Check against a numeric or library reference **after** attempting it.
5. Log mistakes, learning rate, data split and results. A video is not evidence of mastery.

The specialization's course outline is publicly listed; paid lab access and certificates depend on the current provider plan. **Don't pay just for a badge** unless you separately want a certificate.
