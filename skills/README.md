# Reusable study skills

These `SKILL.md` files are **instructions for an AI assistant**, not a substitute for studying, and not code packages that automatically train models.

| Skill | Role |
|---|---|
| [ai-learning-mentor](ai-learning-mentor/SKILL.md) | Tutor using short explanations, your attempts, tests and evidence |
| [ml-debugger](ml-debugger/SKILL.md) | Diagnose without rewriting the entire implementation |
| [research-reproduction](research-reproduction/SKILL.md) | Investigate research claims and reproduce controlled experiments |

**Claude Code:** copies are installed in `.claude/skills/` as project-local skills, available when Claude Code runs in the repository, subject to your Claude Code version/settings.

**ChatGPT:** upload the repository or relevant files to a project/workspace, or paste [prompts/chatgpt-study.md](../prompts/chatgpt-study.md) with the week file. The presence of `SKILL.md` on GitHub **doesn't auto-install it into all ChatGPT conversations**.

Keep your learning goals above agents' urge to write finished solutions immediately.
